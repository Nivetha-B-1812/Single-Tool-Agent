🤖 Single Tool Agent

A simple and interactive AI-powered Single Tool Agent built with Python. The application can understand user queries and use a calculator tool to perform mathematical operations through a web-based interface.

✨ Features

- 🤖 AI Agent-based interaction
- 🧮 Calculator tool for mathematical operations
- 🌐 Simple and responsive web interface
- ⚡ Fast query processing
- 📱 Mobile-friendly design
- 🔧 Modular Python project structure
- 🎨 Clean HTML, CSS and JavaScript frontend

- Git & GitHub

🚀 Getting Started

1. Clone the repository

git clone https://github.com/Nivetha-B-1812/Single-Tool-Agent.git

2. Open the project

cd Single-Tool-Agent

3. Create a virtual environment

python -m venv venv

4. Activate the virtual environment

Windows:

venv\Scripts\activate

Linux / macOS / Termux:

source venv/bin/activate

5. Install dependencies

pip install -r requirements.txt

6. Run the application

python app.py

Then open the local URL displayed by Flask in your browser.
